WebSocket auto test

Runs the M0 browser checks of the echo socket (/ws/echo) unattended, in about seven minutes: messages, the 64 KiB limit, closing, a closed tab, a removed frame, a long idle period, periodic traffic, many sockets at once and a page reload. For each close it also asks the server what it saw. Click Start, then leave the page alone. It's fine to switch to another tab or window; the report says whether the page was hidden. At the end the report is shown here and sent to the server log.

Status: loading

Start opens a second tab for a moment (the closed-tab check) and closes it again. If the browser blocks it, that check is skipped.
